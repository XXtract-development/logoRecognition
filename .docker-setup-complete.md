## 🚀 Quick Start

### Start de API

```bash
# Start container
docker-compose up -d api

# Test health endpoint
curl http://localhost:8000/health

# Expected output:
# {"status":"ok","timestamp":"2025-11-03T20:30:00.000Z"}
```

### Development Workflow

```bash
# View logs (real-time)
docker-compose logs -f api

# Edit code in apps/api/src/
# → Changes auto-reload dankzij --watch flag

# Restart container
docker-compose restart api

# Stop container
docker-compose stop api
```

### Gebruik de API

**JavaScript/Node.js:**
```javascript
const response = await fetch('http://localhost:8000/health');
const data = await response.json();
console.log(data); // { status: 'ok', timestamp: '...' }
```

**React Component:**
```jsx
import { useQuery } from '@tanstack/react-query';

function APIStatus() {
  const { data } = useQuery({
    queryKey: ['health'],
    queryFn: () => fetch('http://localhost:8000/health').then(r => r.json())
  });

  return <div>Status: {data?.status}</div>;
}
```

**cURL:**
```bash
curl http://localhost:8000/health
```

## 🔧 Container Details

### Dockerfile (`apps/api/Dockerfile.dev`)

```dockerfile
FROM node:20-alpine
RUN npm install -g pnpm

WORKDIR /app
COPY package.json pnpm-workspace.yaml pnpm-lock.yaml ./
COPY apps/api/package.json ./apps/api/

RUN pnpm install --frozen-lockfile

COPY apps/api ./apps/api
WORKDIR /app/apps/api

EXPOSE 8000
CMD ["node", "--watch", "src/main-simple.js"]
```

**Optimalisaties:**
- ✅ Alpine Linux (klein & snel)
- ✅ pnpm (sneller dan npm)
- ✅ Multi-stage build ready
- ✅ Hot reload met --watch
- ✅ Layer caching geoptimaliseerd

### Docker Compose

```yaml
api:
  build:
    context: .
    dockerfile: apps/api/Dockerfile.dev
  container_name: logo-recognition-api
  ports:
    - "8000:8000"
  volumes:
    - ./apps/api/src:/app/apps/api/src  # Hot reload
  environment:
    - NODE_ENV=development
    - PORT=8000
    - HOST=0.0.0.0
  networks:
    - logo-recognition
  restart: unless-stopped
```
