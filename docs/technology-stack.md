| `types/index.ts` | Shared TypeScript types |

**Error Handling Features:**
- RFC 7807 compliant error format
- Error classification (ValidationError, AuthError, RateLimitError, etc.)
- Recovery suggestions
- Error budget tracking

**Circuit Breaker States:**
- CLOSED (normal operation)
- OPEN (failing, using fallback)
- HALF_OPEN (testing recovery)

**Caching Architecture:**
- L1: In-memory LRU cache
- L2: Redis cache with retry strategy
- L3: CDN (handled at edge)

**Docker Compose (Development):**
```yaml

  api:     # Fastify (port 8000)
```

**Kubernetes (Production):**
- Namespace: `logo-recognition`
- API Deployment: 3 replicas, HPA (3-20 pods)
- PostgreSQL StatefulSet: 3 replicas, replication enabled
- Redis Deployment: 3 replicas, 2GB maxmemory

## 8. Key Architectural Patterns

### Frontend Patterns

### Backend Patterns
