## Story Statement

**As a** Technical Lead
**I want** current performance metrics captured with historical trends for all frontend components
**So that** we can measure migration impact and detect any regressions during the consolidation process

---

## Acceptance Criteria

1. **Bundle size analysis per route completed** with detailed breakdown of JS/TS components
2. **Performance metrics captured** including FCP, TTI, LCP, CLS, FID for all pages
3. **Memory usage patterns documented** for both legacy JS and modern TS components
4. **API response time baselines** recorded (p50, p95, p99) for all frontend API calls
5. **User interaction flows recorded** using session replay for critical paths
6. **Lighthouse scores documented** for all major routes and pages
7. **Custom metrics defined and captured** for component-specific performance
8. **Historical trend analysis** completed for last 30 days of metrics
9. **Automated baseline comparison tool created** for continuous monitoring
10. **Performance report generated** with executive summary and technical details

### Implementation Code Template

```typescript
// File: frontend/src/migration/performance/BaselineCapture.ts
interface PerformanceBaseline {
  timestamp: number;
  metrics: {
    bundle: {
      total: number;
      perRoute: Record<string, number>;
      chunkSizes: ChunkAnalysis[];
    };
    runtime: {
      fcp: number;
      tti: number;
      lcp: number;
      cls: number;
      fid: number;
    };
    memory: {
      heapUsed: number;
      heapTotal: number;
      external: number;
      arrayBuffers: number;
    };
    api: {
      uploadLatency: Percentiles;
      fetchLatency: Percentiles;
      annotationSave: Percentiles;
    };
    custom: {
      imageLoadTime: number;
      annotationRenderTime: number;
      navigationTransition: number;
    };
  };
}

class BaselineService {
  async captureBaselines(): Promise<PerformanceBaseline> {
    const baseline: PerformanceBaseline = {
      timestamp: Date.now(),
      metrics: await this.gatherAllMetrics()
    };

    await this.storeInIndexedDB(baseline);
    await this.uploadToMonitoring(baseline);
    await this.generateReport(baseline);

    return baseline;
  }
}
```
