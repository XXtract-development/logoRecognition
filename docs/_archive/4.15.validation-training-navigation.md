# Story 4.15: Validation & Training Navigation

## Status

## Story
**As a** Data Manager (Jan),
**I want** to proceed to training only when all logos are correctly categorized with validation and auto-save,
**so that** the machine learning model is trained with complete and accurate data.

## Acceptance Criteria
1. Validation rules enforcement - "Continue to Training" button disabled until all bounding boxes have category and value
2. Real-time validation feedback - Button status updates immediately with each annotation change
3. Progress tracking display - Progress bar shows completion percentage and counter "X of Y logos categorized"
4. Visual validation indicators - Incomplete preview cards highlighted with clear error messages
5. Navigation flow control - Continue button navigates to training with proper data handoff
6. Auto-save functionality - Progress automatically saved every 30 seconds with recovery capability
7. Data integrity validation - Prevents duplicate category-value combinations and validates coordinates
8. Navigation guards - Confirms navigation when unsaved changes exist with recovery options
9. Error recovery system - Handles browser crashes, network failures, and validation conflicts

#### Validation Logic Implementation
[Source: stories/US-012-validation-training-navigation.md#validation-state-management]

```typescript
const useValidation = (annotations: LogoAnnotation[]): ValidationState => {
  return useMemo(() => {
    const errors: ValidationError[] = [];
    const incompleteIds: string[] = [];

    // Completeness validation
    annotations.forEach(annotation => {
      if (!annotation.category) {
        errors.push({
          id: `${annotation.id}-category`,
          annotationId: annotation.id,
          type: 'missing_category',
          message: 'Category is required for training',
          field: 'category',
          severity: 'error'
        });
        incompleteIds.push(annotation.id);
      }

      if (!annotation.value?.value?.trim()) {
        errors.push({
          id: `${annotation.id}-value`,
          annotationId: annotation.id,
          type: 'missing_value',
          message: 'Value is required for training',
          field: 'value',
          severity: 'error'
        });
        if (!incompleteIds.includes(annotation.id)) {
          incompleteIds.push(annotation.id);
        }
      }
    });

    // Duplicate detection
    const combinations = new Map<string, string[]>();
    annotations.forEach(annotation => {
      if (annotation.category && annotation.value) {
        const key = `${annotation.category.name}-${annotation.value.value}`;
        if (!combinations.has(key)) {
          combinations.set(key, []);
        }
        combinations.get(key)!.push(annotation.id);
      }
    });

    combinations.forEach((ids, combination) => {
      if (ids.length > 1) {
        ids.forEach(id => {
          errors.push({
            id: `${id}-duplicate`,
            annotationId: id,
            type: 'duplicate',
            message: `Duplicate combination: ${combination}`,
            severity: 'warning'
          });
        });
      }
    });

    const completedCount = annotations.length - incompleteIds.length;
    const isComplete = incompleteIds.length === 0 && annotations.length > 0;
    const hasBlockingErrors = errors.some(e => e.severity === 'error');

    return {
      isComplete,
      completedCount,
      totalCount: annotations.length,
      incompleteAnnotations: incompleteIds,
      validationErrors: errors,
      canProceedToTraining: isComplete && !hasBlockingErrors,
      lastValidated: new Date()
    };
  }, [annotations]);
};
```

### Navigation Guard Implementation
[Source: architecture/router/guards, architecture/10-frontend-architecture.md]

#### Browser Navigation Protection
```typescript
const useNavigationGuard = (hasUnsavedChanges: boolean) => {
  useEffect(() => {
    const handleBeforeUnload = (event: BeforeUnloadEvent) => {
      if (hasUnsavedChanges) {
        event.preventDefault();
        event.returnValue = 'You have unsaved annotations. Are you sure you want to leave?';
      }
    };

    window.addEventListener('beforeunload', handleBeforeUnload);
    return () => window.removeEventListener('beforeunload', handleBeforeUnload);
  }, [hasUnsavedChanges]);

  const confirmNavigation = useCallback((destination: string, callback: () => void) => {
    if (hasUnsavedChanges) {
      Modal.confirm({
        title: 'Unsaved Changes',
        content: 'You have unsaved annotations. Do you want to save before continuing?',
        okText: 'Save & Continue',
        cancelText: 'Discard & Continue',
        onOk: async () => {
          await triggerManualSave();
          callback();
        },
        onCancel: callback
      });
    } else {
      callback();
    }
  }, [hasUnsavedChanges]);

  return { confirmNavigation };
};
```
