# Registration contract
Codes normalize by trim/uppercase. Specific dietary, nutritional, usage and GHS lists win over generic accreditation overlap. Unknown nonempty codes retain PackagingMarkedLabelAccreditationCode / packagingMarkedLabelAccreditationCode. Blank codes and conflicting explicit fields are invalid. Shared data defines lists and declaration fields; existing TS resolver remains the public API. ML independently resolves and validates explicit metadata; direct Python callers use the same source.
Same-path lookup includes inactive rows. Repair is permitted only when canonical codes match and touches category metadata only. Different-code same-path requests return a conflict and never modify labels. New crops retain load, embedding, near-duplicate and unique-variant guards.
All review-registration calls plus realref_live.py and seed-reference-logos.ts use the contract. Existing backfill reads and reports category differences; root owns exact external repair manifest and authorization.

Non-string codes are invalid. All same-path legacy matches must share the requested canonical code before repair; mixed-code matches are rejected without updates. Backfill applies only an explicitly supplied approved manifest and guards original code, active state, field_type and gs1_field under row lock.

Reviewed final contract: version2 binds environment label plus actual database/serverAddress/serverPort, checked before writes. Every allowed row returns a written, already-correct or skipped-race reason; incomplete CLI returns status1. Manifestpreview including wrapper teardown uses zero Prisma calls. Samepath registration holds a nonblocking transaction-scoped advisory lock through lookup and atomic logo/embedding insertion; in-flight duplicate requests perform no writes, other paths proceed. Seed lookup precedes image availability and repair updates only matching id+original code.
